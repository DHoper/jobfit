# Chrome 線上應用程式商店上架資料

## 名稱

避雷針：職缺避雷與評估

## 簡短說明（132 字以內）

打開職缺就標出責任制、薪資面議、綁約等台灣職缺地雷，再對照你的經歷判斷值不值得投。支援 104、1111、Cake、Yourator、LinkedIn。

## 詳細說明

投履歷之前，先知道這份工作值不值得投。

避雷針在你打開職缺時，當下標出台灣職缺常見的地雷，再對照你自己的經歷，告訴你該投、再想想，還是別投。

【當下就看得到的地雷】
・27 條台灣職缺規則：責任制、需配合加班、薪資含加班費、低於最低工資、試用期打折、綁約違約金、承攬不保勞健保、月休不足、要你加 LINE、要先付錢、海外高薪等
・直接在職缺頁上用螢光筆標出原文，工具列圖示顯示地雷數量
・「非責任制」「不需輪班」這類否定寫法不會誤判

【你的底線】
・設定薪資底線和不能接受的條件，碰到就直接建議跳過
・自訂關鍵字，例如產業或合約條款

【對照你的經歷】
・逐項列出職缺要求，標示你符合、部分符合或缺少，並引用你自己的經歷當依據
・AI 只根據你提供的內容判斷，不會替你編造經歷
・給你面試時該問清楚的問題，以及履歷該強調的經歷
・上傳 PDF 或 Word 履歷就能建立個人檔案

【投遞紀錄】
・記錄想投、已投遞、面試中、offer、沒上
・看自己的面試率，以及 AI 建議和實際結果對不對得上
・匯出 CSV

【隱私】
・個人檔案和紀錄只存在你的電腦
・送給 AI 前自動移除姓名、電話、Email 等個資
・不追蹤、不放廣告、不自動投遞

## 權限說明（審查用）

| 權限 | 用途 |
| --- | --- |
| sidePanel | 在側邊欄顯示職缺評估 |
| storage | 在本機保存個人檔案、投遞紀錄、設定 |
| scripting、activeTab | 讀取目前職缺頁的內容，並在頁面上標示地雷字詞 |
| 主機權限：104、1111、Cake、Yourator、LinkedIn | 在這些求職網站自動讀取職缺內容、顯示地雷數量 |
| 主機權限：api.deepseek.com、*.workers.dev | 呼叫 AI 評估服務 |
| 選用主機權限：https://*/* | 使用者在其他網站按「允許讀取這個網站」時才會要求，只授權那一個網站 |

## 單一用途說明

幫求職者評估正在瀏覽的職缺：偵測不利的勞動條件，並對照使用者的經歷判斷是否適合投遞。
