# 避雷針隱私權政策

最後更新：2026 年 11 月 27 日

避雷針是一個 Chrome 擴充功能，幫你在求職網站上判斷職缺值不值得投。這份文件說明它會碰到哪些資料、存在哪裡、送到哪裡。

## 存在你電腦裡的資料

以下資料只存在你這台電腦的 Chrome 裡（`chrome.storage.local`），不會上傳到避雷針的伺服器：

- 你填寫或上傳的個人檔案：經歷、技能、成果、職涯目標、薪資底線、不能接受的條件、舊履歷文字
- 投遞紀錄：你評估或加入紀錄的職缺標題、公司、網址、評估結果、投遞狀態、筆記
- 設定：AI 服務網址、你自己填的 DeepSeek 金鑰（如果有）

上傳的 PDF 或 Word 履歷只在你的瀏覽器裡轉成文字，檔案本身不會離開你的電腦。

你可以隨時在「設定與資料」匯出、清除投遞紀錄；移除擴充功能時，Chrome 會刪除所有資料。

## 讀取網頁內容

- 在 104、1111、Cake、Yourator、LinkedIn 的頁面上，避雷針會讀取職缺內容，用來偵測地雷字詞、在工具列圖示顯示數量，並在頁面上標示原文。
- 其他網站只有在你按下「允許讀取這個網站」之後才會讀取。
- 地雷偵測完全在你的瀏覽器裡執行，不會送出任何資料。

## 送給 AI 的資料

只有在你按下「對照我的經歷評估」或「用 AI 整理」時，才會把以下內容送給 AI 服務：

- 這個職缺的內容
- 你的個人檔案（預設會先移除姓名、電話、Email、地址、生日、身分證字號，可在設定關閉）

資料會經過避雷針的代理伺服器（Cloudflare Worker）轉送給 DeepSeek。代理伺服器不儲存、不記錄你的內容，只為了每日次數限制記錄連線 IP 的使用次數，保存不超過 26 小時。DeepSeek 如何處理資料，請參考 [DeepSeek 的隱私權政策](https://www.deepseek.com/)。

如果你在設定裡填了自己的 DeepSeek 金鑰，資料會直接從你的瀏覽器送到 DeepSeek，不經過代理伺服器。

## 不會做的事

- 不追蹤你的瀏覽紀錄，不收集分析資料，不放廣告
- 不出售或分享你的資料給任何第三方
- 不會自動幫你投遞履歷
